## TechDrop

Aplicación de subastas de productos en tiempo real.

### Características principales

- **Sistema de autenticación y autorización** robusto
- **Subastas en tiempo real** usando SignalR
- **Notificaciones instantáneas** sobre el estado de las subastas
- **Gestión de usuarios** con roles y permisos

### Tecnologías utilizadas

- C# con ASP.NET Core para el backend
- SQL Server para la base de datos
- SignalR para comunicación en tiempo real
- Bootstrap para el diseño responsivo
- JavaScript para interactividad del lado del cliente
