## LYM (Look Your Mood)

Plataforma de e-commerce revolucionaria enfocada en Moda y Accesorios de Vestir.

### Características

- **Productos personalizables** de alta calidad
- **Carrito de compras** intuitivo
- **Sistema de autenticación** seguro
- **Panel de administración** completo

### Stack técnico

- PHP para el backend y lógica de servidor
- React para una interfaz dinámica y reactiva
- MySQL para almacenamiento de datos
- JavaScript moderno y Tailwind CSS
