## SpCarrillos

Aplicación web diseñada para la iglesia local de Carrillos, Poás, con un enfoque en:

- **Arquitectura limpia** y mantenible
- **Rendimiento optimizado** en producción
- **Experiencia de usuario** fluida e intuitiva

### Tecnologías

- HTML5 semántico y accesible
- JavaScript moderno (ES6+)
- Tailwind CSS para estilos rápidos y consistentes
- Alpine.js para interactividad ligera
